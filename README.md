# 貸款與投資現金流試算器

一個以繁體中文呈現、可在瀏覽器本機執行的單一年期試算工具。輸入貸款、投資、匯率和配息條件後，頁面會列出每月還款、配息、現金缺口與預計清償結果。所有數值計算都在瀏覽器內進行，沒有伺服器端帳號或資料上傳功能。

[開啟線上示範](https://nemo-ifa.github.io/carrytrade/)

**English:** A browser-only calculator for comparing loan repayments with a fixed-yield investment cash-flow scenario. The interface and assumptions are documented in Traditional Chinese.

## 使用方式

1. 下載本儲存庫並開啟 `index.html`。保持 `calendar.js` 與 `index.html` 在同一資料夾。
2. 修改左側輸入條件。結果、圖表及明細表會即時更新。
3. 用「列印 / 存成 PDF」保存目前的試算結果。

不需要安裝套件，也不需要提供銀行帳號或個人資料。

## 計算範圍與假設

- 貸款採每月本息攤還；月利率以輸入的年利率除以 12 計算。也可手動指定月付金。
- 投資收益以輸入的固定年化率、365 或 360 天計息基礎計算。此為**情境假設**，不是對任何投資報酬的承諾。
- 配息月份與日期可設定；試算會顯示固定配息及到期尾段補配。
- 美元金額以單一輸入匯率換算為新台幣；工具不預測未來匯率。
- 月繳不足、起始資金不足、提前清償違約金會分別顯示。未輸入的稅費、手續費和其他契約成本不會自動計入。
- 月底日期會對齊到目標月份的最後一天，避免將 1 月 31 日加一個月算成 3 月。

請自行核對貸款契約、投資條款、配息日、匯率與稅費。此工具只供比較情境，不提供投資建議。
